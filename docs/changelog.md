
# Changelog

Todas as mudanças relevantes deste projeto serão documentadas neste arquivo.

O formato é baseado em Keep a Changelog e versionamento semântico (SemVer).

---

## [1.1.0] - 2026-11-16

### Adicionado

- Landing Page corporativa do SCF.
- Navegação superior responsiva.
- Tema claro e escuro (Dark Mode).
- Seção "O que é o SCF".
- Seção "Resultados Comprovados".
- Seção "Como o SCF Garante a Execução".
- Seção "Controle e Conformidade".
- Seção "Ecossistema Integrado".
- Seção "KPI Engine".
- Seção "Real-Time Visual Management Dashboards".
- Seção "Segmentos Atendidos".
- Seção "Sobre a Sistemas Computacionais".
- Seção "Por Que Escolher o SCF?".
- Formulário de contato baseado em FormSubmit.
- Selos de validação HTML5 e CSS3.
- Branding visual para a marca SCF.

### Melhorado

- Identidade visual corporativa.
- Responsividade para dispositivos móveis.
- Contraste e legibilidade do componente central do Ecossistema Integrado.
- Estrutura semântica do HTML.
- Organização do CSS.
- Navegação entre seções.
- Experiência visual do Hero.
- Estilização dos cartões (cards).
- Layout do formulário de contato.

### Corrigido

- IDs duplicados identificados pelo W3C.
- Estrutura HTML inválida.
- Seções sem fechamento adequado.
- Problemas de navegação por âncoras.
- Conflitos de CSS no modo escuro.
- Contraste inadequado em componentes da seção Ecossistema Integrado.

### Validação

- HTML validado pelo W3C.
- CSS validado pelo W3C.
- Compatibilidade com CSS Level 3 + SVG confirmada.
